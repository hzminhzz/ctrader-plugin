# cTrader Prop Risk Manager

Open-source cTrader desktop Plugin project for risk-based execution and prop-firm account protection.

The project is being built in stages:

1. Native cTrader Plugin shell and execution panel
2. Draggable Entry / Stop Loss / Take Profit chart overlay
3. Risk-based position sizing and pre-trade validation
4. Account-level daily-loss / max-drawdown guardian
5. Breakeven, trailing stop, partial exits, presets, and statistics

## Status

Initial repository scaffold. Active development.
